# Login Page UI

Built for **Synent Technologies Web Development Internship — Task 3 (Basic Level)**.

## What it is
A clean, modern login interface with a split-screen layout — a branding panel on the left and the sign-in form on the right.

## Features
- Email and password input fields with focus states
- Show/Hide password toggle
- "Remember me" checkbox and "Forgot password?" link
- Submit shows a demo alert (no backend — this is a UI-only task)
- Fully responsive — stacks vertically on mobile

## Tech
- Plain **HTML5**, **CSS3**, and a small amount of vanilla **JavaScript** (password toggle + form handling)
- No framework, no libraries
